# 구조역학 시각화 랩

SFD·BMD·처짐, 트러스 절점법·절단법을 눈으로 보며 이해하는 학습용 웹앱입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 구성
| 페이지 | 내용 |
|---|---|
| 기초 개념 | 지점과 반력, V·M 부호 규약, 하중→전단력→모멘트→처짐 관계, 인장/압축 |
| 보 해석 | 단순보·캔틸레버·내민보·일단고정타단롤러·양단고정보 / 집중·등분포·삼각형·모멘트 하중 (드래그 이동) / 하중도·SFD·BMD·처짐 / 커서 위치의 단면력 / 단계별 풀이와 공식 검산 |
| 트러스 | 프랫·하우·워렌·지붕 트러스 / 인장·압축 색과 화살표 / 변형 애니메이션 / 절점법 단계 진행 / 절단법 절단 위치·모멘트 중심 표시 |

## 계산 방법
- 보: 오일러-베르누이 보 요소 강성법으로 반력·처짐을 구하고, SFD/BMD는 단면 왼쪽 부분의 평형으로 정확히 계산
- 트러스: 절점 평형방정식(2j개)을 연립해 부재력·반력 계산. 인장 +, 압축 −
- 단위: m, kN, kN·m, E [GPa], I [10⁶ mm⁴], 처짐 [mm]

## 파일
- `index.html` — 페이지 구조
- `css/style.css` — 스타일 (라이트/다크)
- `js/common.js` — SVG 도우미, 선형방정식 풀이
- `js/concept.js` — 개념 페이지 그림
- `js/beam.js` — 보 해석·그리기·풀이 과정
- `js/truss.js` — 트러스 해석·절점법·절단법
- `js/app.js` — 페이지 전환, 테마
