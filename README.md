# 구조역학 시각화 랩

대학 구조역학(정역학 → 보 → 단면 → 트러스 → 기둥)을 3D 모델과 애니메이션으로 공부하는 학습 웹앱입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 동작합니다. (3D 화면은 Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 학습 모듈
| 모듈 | 내용 |
|---|---|
| 학습 홈 | 학습 경로와 진도(브라우저에 저장), 3D 보 데모 |
| 기초 개념 | 지점·반력, 정정·부정정, V·M 부호 규약, w–V–M–θ–δ 관계, 인장·압축, 트러스 정정 판별 |
| 보 해석 | 단순보·캔틸레버·내민보·일단고정타단롤러·양단고정보 / 집중·등분포·삼각형·모멘트 하중(드래그 이동) / 3D 휨 변형과 휨응력 색 / SFD·BMD·처짐 / 단면 따라 그리기 애니메이션 / 단계별 풀이·공식 검산·휨응력 검토 |
| 단면과 응력 | 직사각형·H형강·T형·원형 / 평행축 정리 표 / 응력 블록(사투상) / σ = My/I, τ = VQ/Ib 분포 |
| 트러스 읽는 법 | 부재 하나의 인장·압축 / 부재 기준 vs 절점 기준 화살표(분리 애니메이션) / 절점 순서 고르기 게임과 분해 보기 / 가위로 자르는 절단 규칙 검사·모멘트 중심 표시 / 화살표 읽기 퀴즈 |
| 트러스 | 프랫·하우·워렌·지붕 / 인장·압축 색과 화살표 / 3D 교량과 힘의 흐름 / 절점법 단계 진행 / 절단법 모멘트 중심 표시 |
| 기둥 좌굴 | 지지 조건별 K와 좌굴 모드 / 오일러 하중 / 초기 처짐 증폭 / 세장비–좌굴응력 곡선(KDS·AISC 설계 곡선 비교) |
| 연습문제 | 반력·최대 모멘트·부재력·단면 성질·처짐·좌굴하중 문제를 무작위 생성, 자동 채점과 풀이 |

## 계산 방법
- 보: 오일러-베르누이 보 요소 강성법으로 반력·처짐, SFD/BMD는 단면 왼쪽 부분의 평형으로 계산
- 트러스: 절점 평형방정식(2j개) 연립으로 부재력·반력, 변형은 축강성 행렬로 계산
- 단면: 직사각형 분할 + 평행축 정리, Q(y)는 수치 적분
- 단위: m, kN, kN·m, MPa, mm

## 파일
- `index.html` — 앱 셸과 각 페이지
- `css/style.css` — 스타일 (라이트/다크)
- `js/common.js` — SVG 도우미, 선형방정식 풀이
- `js/viewer3d.js`, `js/beam3d.js`, `js/truss3d.js` — Three.js 3D 뷰
- `js/concept.js` — 개념 그림, 홈 3D 데모
- `js/guide.js` — 트러스 읽는 법 (부재·절점·절단 화살표 규칙)
- `js/beam.js`, `js/section.js`, `js/truss.js`, `js/column.js`, `js/quiz.js` — 각 모듈
- `js/app.js` — 라우팅, 진도, 테마
